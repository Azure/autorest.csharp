# AutoRest Code Generator for C# Packages

The AutoRest code generator for C# has reached end-of-life and is no longer published nor supported.  As part of retirement, this repository has been archived and is no longer maintained.

## TypeSpec Generator Migraion

Microsoft recommends authoring REST API specifications in [TypeSpec](https://azure.github.io/typespec-azure/docs/intro/) and provides an unbranded C# code generator for TypeSpec [here](https://github.com/microsoft/typespec/tree/main/packages/http-client-csharp) and an Azure-focused C# code generator for TypeSpec [here](https://github.com/Azure/azure-sdk-for-net/tree/main/eng/packages/http-client-csharp).
